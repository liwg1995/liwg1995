### [YuduBid · 禹都 AI 解决方案助手](https://github.com/liwg1995/YuduBid)

**让专业文档创作更智能，让复杂工作流程更简单。**

YuduBid 是一款面向实际工作场景的 AI 桌面助手，围绕 **售前解决方案、技术标书、项目材料与智能文档处理**，将资料整理、章节规划、内容生成、校审和 Word 导出衔接为更连贯的工作流程。
